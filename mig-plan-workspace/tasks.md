# Migration Tasks: CoolStore Monolith (JBoss EAP 7.4 / Java EE 7 / Java 8) → Quarkus 3.15 LTS / Java 21 on OpenShift

> Generated by mig-plan (MigIQ Phase 3) in autonomous mode.
> Foundation: `mig-prompt-workspace/migration-prompt.md`. Design decisions D1-D13 are referenced as `[Dx]`.
> Approach: big bang, single module. Phase 4 executes the groups in order.
> **Integration hooks:** the `mig-test-gen`, `mig-containerize` and `mig-deploy` subtasks are specified here and are carried out in Phase 4 execution. They were not run during planning, because this stage must not modify application source. No JDK, Maven, container engine or `oc` is available in the sandbox, so every "verify" step runs in CI or on OpenShift.
