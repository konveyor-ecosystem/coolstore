# Migration Tasks: Coolstore Java EE 7 → Quarkus 3.15 LTS / Java 21 on OpenShift

> Generated by **mig-plan** (MigIQ Phase 3) on 2026-10-23.
> The specification and design are in [`mig-prompt-workspace/migration-prompt.md`](../mig-prompt-workspace/migration-prompt.md). Sections referenced as §… point there.
> Inputs: rgctl index (`.rgctl/migration_plan.json`, hybrid_default, 155 steps), `.konveyor/analysis.json`, `rules/rule.yaml`.
> Strategy: **big bang, single-pass refactor** on a migration branch. Execute the groups in order and keep the build green at the end of each group, starting from Group 2.
>
> **Integration hooks:** the mig-test-gen, mig-containerize and mig-deploy hooks are written into each group. They run during execution (mig-execute, Phase 4) and are not run in this planning phase. Phase 2/3 may write only to `mig-*-workspace/`, while those skills write tests, Containerfiles and manifests into the source tree. The groups named after them (7, 8, 9) produce the final artifacts. The hooks in the earlier groups add the configuration and requirements that group needs.

**Environment for every group:** `export JAVA_HOME=/tmp/jdk PATH=/tmp/jdk/bin:/tmp/mvn/bin:$PATH`. Maven Central is reachable. Podman/docker and an OpenShift cluster are **not** available, so image builds and `oc apply` are replaced by static validation.

**Traceability to rgctl `migration_plan.json`:** `rest` (step 18, highest Java priority 0.033) → `service` (17) → `utils` (16) → `model` (15) → `persistence` (45) and the `weblogic.*` stubs (33, 38). `max_blast` is 0 for every Java package, so Groups 3–6 have small cross-package ripple. They are ordered by compile dependency (model → service → messaging → rest).
